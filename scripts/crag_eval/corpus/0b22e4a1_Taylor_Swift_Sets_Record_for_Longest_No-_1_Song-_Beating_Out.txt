      <h1 class="headline" itemprop="headline">Taylor Swift Sets Record for Longest No. 1 Song, Beating Out &#8216;American Pie&#8217; and the Beatles</h1>
      <p class="subtitle" itemprop="description">The pop star&#8217;s 10-minute, 13-second rerecording of &#8220;All Too Well&#8221; debuted at the top spot in Billboard&#8217;s Hot 100 chart</p>

      
        <div class="article-line">
          

<section class="author-box by-line single-author">
  
    
      
        <div class="author-headshot smart-news">
          <img src="https://th-thumbnailer.cdn-si-edu.com/B8yP3I4JzhX5dMd2GGsEy2fPzNI=/fit-in/160x80/filters:no_upscale()/https://tf-cmsv2-smithsonianmag-media.s3.amazonaws.com/accounts/headshot/nora.png" alt="Nora McGreevy" class="headshot" />
        </div>
      
    
  
  <div class="author-text">
  
    
      
        <p class="author" itemprop="author">
        
        
          <a href='/author/nora-mcgreevy/'>Nora McGreevy</a>
        
        </p>
      
      
    

    
      
        <p class="author-short-bio">Correspondent</p>
      
    
    
      <time class="pub-date" itemprop="datePublished" data-pubdate="Nov. 24, 2021, 10:26 a.m.">November 24, 2021</time>
    
  
  </div>
  <hr />
</section>

        </div>
      
    </header>

    <div class="article-columns">
      <div class="articleLeft" data-article-body>
        
          <figure class="article-image lead-article-image">
            <img src="https://th-thumbnailer.cdn-si-edu.com/8IDXLjNz4JYkMMJJgUfpl3bhcPY=/1000x750/filters:no_upscale():focal(1443x686:1444x687)/https://tf-cmsv2-smithsonianmag-media.s3.amazonaws.com/filer_public/72/88/72887d78-cfea-4868-b2d5-94d5f86f3ae2/gettyimages-1236560335.jpg"
                 alt="Swift performs in front of a dark blue stage, with lights illuminating fake snow falling from the ceiling; she wears a black dress and red lipstick"
                 itemprop="image"/>
            <figcaption class="caption">
              
                Swift&#39;s extended version of &quot;All Too Well&quot; surpassed&nbsp;the length of the previous record holder, Don McLean&#39;s 8-minute, 42-second&nbsp;&quot;American Pie (Parts I and II).&quot;
              <span class="credit">Will Heath / NBC / NBCU Photo Bank / Getty Images</span>
            </figcaption>
          </figure>
        

        <div class="social"
          data-features="32px,circle,opacity,icon-white,pad"
          data-sites="facebook,twitter,linkedin,reddit,whatsapp,pocket,print,email"
          data-meta-instagram="https://instagram.com/smithsonianmagazine"
          data-meta-link="https://www.smithsonianmag.com/smart-news/taylor-swift-beats-out-american-pie-and-the-beatles-for-longest-run-time-of-a-no-1-hit-180979116/"
          data-meta-title="Taylor Swift Sets Record for Longest No. 1 Song, Beating Out &#x27;American Pie&#x27; and the Beatles"
          data-meta-twitterusername="@smithsonianmag">
        </div>

        <p>Pop icon Taylor Swift made music history this week when her epic, ten-minute-long version of “<a href="https://genius.com/Taylor-swift-all-too-well-10-minute-version-taylors-version-live-acoustic-lyrics">All Too Well</a>” debuted at No. 1 on the Billboard <a href="https://www.billboard.com/charts/hot-100/">Hot 100 chart</a>. The song is the longest to ever reach the top spot by a margin of more than a minute, reports Gary Trust for <em><a href="https://www.billboard.com/music/chart-beat/taylor-swift-all-too-well-hot-100-debut-1235001340/">Billboard</a></em>.</p>

<p>Swift’s chart-topper shattered a record that had gone unchallenged since January 1972, when Don McLean’s 8-minute, 42-second single “<a href="https://www.theguardian.com/music/2020/oct/22/don-mclean-american-pie-its-meaning-family-deaths-tragedy-60s">American Pie (Parts I and II)</a>” spent four weeks in the No. 1 spot. Trimmed down for the radio, the full version was so long that the singer’s record label had to split it into <a href="https://www.loudersound.com/features/the-story-behind-american-pie-by-don-mclean">two parts</a> to fit on a double-sided, seven-inch vinyl record. </p>

<p>“Let’s face it, nobody ever wants to lose that No. 1 spot, but if I had to lose it to somebody, I sure am glad it was [to] another great singer/songwriter such as Taylor,” McLean tells <em><a href="https://www.billboard.com/music/pop/don-mclean-reacts-taylor-swift-for-breaking-half-century-american-pie-record-1235001870/">Billboard</a></em>’s Gil Kaufman.</p><figure class="video">
    <div class="embedly-plugin" data-type="video">
        


  

  <div class="video-image">
    <div class="youtube-video-title">All Too Well (10 Minute Version) (Taylor&#x27;s Version) (From The Vault) (Lyric Video)</div>
    <div class="watch-on-youtube"><a href="https://www.youtube.com/watch?v=sRxrwjOtIag" target="_blank">Watch on <img src="/static/smithsonianmag/img/youtube-white-logo.8f2627848a7a.png" alt="YouTube Logo" /></a></div>
    <div class="video-thumbnail"><img src="https://i.ytimg.com/vi/sRxrwjOtIag/maxresdefault.jpg" data-video-id="sRxrwjOtIag" /></div>
  </div>

  <iframe width="854" src="" frameborder="0" id="player" allowfullscreen allow="autoplay"></iframe>

    </div>
    
</figure>
<p>In the week following its November 12 release, Swift’s 10-minute, 13-second ballad was streamed 54.5 million times by listeners in the United States alone. Officially titled “All Too Well (10-Minute Version) (Taylor’s Version) (From the Vault),” the song served as the much-anticipated closing track on Swift’s <a href="https://taylor.lnk.to/redtaylorsversionWE">rerecorded version</a> of her fourth studio album, <em>Red </em>(2012). (The new album debuted at No. 1 on the <a href="https://www.billboard.com/charts/billboard-200/">Billboard 200 chart</a>, making Swift the only artist to have topped both charts simultaneously three times, reports Allison Hussey for <em><a href="https://pitchfork.com/news/taylor-swift-sets-new-record-for-longest-no-1-song-with-all-too-well-10-minute-version/">Pitchfork</a>.</em>)</p>

<p>Swift took to social media to express her <a href="https://twitter.com/taylorswift13/status/1462908807034679303?s=20">excitement</a>.</p>

<p>“I’m floored,” she wrote on <a href="https://twitter.com/taylorswift13/status/1462908809542787072?s=20">Twitter</a>. “A ten-minute song is at the top of the Hot 100.”</p>

<p>Today, pop songs’ length is typically between 3 to 5 minutes. As Kelsey McKinney reported for <em><a href="https://www.vox.com/2014/8/18/6003271/why-are-songs-3-minutes-long">Vox</a></em> in 2015, this industry standard dates to the <a href="http://news.google.com/newspapers?id=H1tWAAAAIBAJ&amp;sjid=7u8DAAAAIBAJ&amp;pg=6991%2C6756292">mid-20th century</a>, when music labels were constrained by how many grooves they could carve into the side of a physical record. At the time, each 45 rpm (revolutions per minute) record held about three minutes of music.</p><figure class="video">
    <div class="embedly-plugin" data-type="video">
        


  

  <div class="video-image">
    <div class="youtube-video-title">The Beatles - Hey Jude</div>
    <div class="watch-on-youtube"><a href="https://www.youtube.com/watch?v=A_MjCqQoLLA" target="_blank">Watch on <img src="/static/smithsonianmag/img/youtube-white-logo.8f2627848a7a.png" alt="YouTube Logo" /></a></div>
    <div class="video-thumbnail"><img src="https://i.ytimg.com/vi/A_MjCqQoLLA/maxresdefault.jpg" data-video-id="A_MjCqQoLLA" /></div>
  </div>

  <iframe width="854" src="" frameborder="0" id="player" allowfullscreen allow="autoplay"></iframe>

    </div>
    
</figure>
<p>Over the years, a number of major artists have bucked this trend. In 1968, for instance, the Beatles topped U.S. charts with their 7-minute, 11-second “<a href="https://www.billboard.com/pro/the-beatles-hey-jude-this-week-in-billboard-chart-history-1968/">Hey Jude</a>.” Four years later, in 1972, a pared-down, seven-minute <a href="https://www.myradiolink.com/2021/10/13/flashback-the-temptations-release-papa-was-a-rollin-stone/">edit</a> of the Temptations’ “<a href="https://www.history.com/this-day-in-history/the-temptations-earn-their-final-1-hit-with-papa-was-a-rolling-stone">Papa Was a Rollin’ Stone</a>,” which originally clocked in at more than 12 minutes long, managed to cinch the No. 1 slot.</p>

<p>Also released in 1972, McLean’s “<a href="https://genius.com/Don-mclean-american-pie-lyrics">American Pie</a>” enthralled audiences with its colorful allusions to recent music and world history, all set to a bouncy rhythm. The song hinged on what McLean famously dubbed “<a href="https://www.history.com/this-day-in-history/the-day-the-music-died">the day the music died</a>”: February 3, 1959, when young Rock ‘n’ Roll stars Buddy Holly, Ritchie Valens and J.P. “the Big Bopper” Richardson died in a <a href="https://www.biography.com/news/the-day-the-music-died--plane-crash">plane crash</a>. The track was <a href="https://www.loc.gov/item/prn-17-029/">inducted</a> into the Library of Congress’ <a href="https://www.loc.gov/programs/national-recording-preservation-board/recording-registry/complete-national-recording-registry-listing/">National Recording Registry</a> in 2017 alongside such cultural touchstones as Judy Garland’s “Over the Rainbow” and N.W.A.’s seminal album <em>Straight Outta Compton</em>.</p><figure class="video">
    <div class="embedly-plugin" data-type="video">
        


  

  <div class="video-image">
    <div class="youtube-video-title">Don McLean - American Pie (Lyric Video)</div>
    <div class="watch-on-youtube"><a href="https://www.youtube.com/watch?v=PRpiBpDy7MQ" target="_blank">Watch on <img src="/static/smithsonianmag/img/youtube-white-logo.8f2627848a7a.png" alt="YouTube Logo" /></a></div>
    <div class="video-thumbnail"><img src="https://i.ytimg.com/vi/PRpiBpDy7MQ/maxresdefault.jpg" data-video-id="PRpiBpDy7MQ" /></div>
  </div>

  <iframe width="854" src="" frameborder="0" id="player" allowfullscreen allow="autoplay"></iframe>

    </div>
    
</figure>
<p>Much like the lengthy No. 1 hits of decades past, “All Too Well” tackles big emotions with catchy, heartfelt refrains. Though <em><a href="https://www.nytimes.com/2021/11/15/arts/music/taylor-swift-all-too-well.html">New York Times</a> </em>critic Lindsay Zoladz argues that the shorter version of “All Too Well” is “the better song,” in part because of “the elegant simplicity of its structure,” she adds that “the power of the new version comes from its unapologetic messiness, the way it allows a woman’s subjective emotional experience to take up a defiantly excessive amount of time and space.”</p>

<p>“All Too Well” also embodies—and for some, <a href="https://www.washingtonpost.com/arts-entertainment/2021/11/12/taylor-swift-all-too-well-ten-minutes/">defines</a>—the heartbreak anthem. In this, too, the song follows a long tradition of American musicians who have wrung melodies from misery. As Gracie Anderson wrote for <em><a href="https://www.smithsonianmag.com/arts-culture/heart-wrenching-history-breakup-album-180978562/">Smithsonian </a></em><a href="https://www.smithsonianmag.com/arts-culture/heart-wrenching-history-breakup-album-180978562/">magazine</a><em> </em>earlier this year, by the 1970s, a generation of singer-songwriters had perfected the so-called “breakup album,” producing such records as Joni Mitchell’s <em><em><a href="https://www.youtube.com/watch?v=VYyyf9rRurc"><em>Blue</em></a></em></em> (1971) and Willie Nelson’s <em><em><a href="https://www.youtube.com/playlist?list=PL3YjT--U7ZohaBm0V8KJ3YSlG7PXWU6E5"><em>Phases and Stages</em></a></em></em> (1973).</p>

<p>Swift co-wrote “All Too Well” with country musician Liz Rose in the early 2010s. In the extended lyrics, a woman in her 20s reflects on a failed relationship with an older man. “Autumn leaves,” the “cold air” of fall and a certain <a href="https://www.insider.com/taylor-swift-jake-gyllenhaal-scarf-timeline-all-too-well-explanation-2021-11">lost scarf</a> become symbols for spoiled innocence and lost love. As Swift sings to her onetime lover:</p>

<blockquote>
<p>And there we are again when nobody had to know</p>

<p>You kept me like a secret, but I kept you like an oath</p>

<p>Sacred prayer and we’d swear</p>

<p>To remember it all too well.</p>
</blockquote>

    function stickyLeaderboardAdOnScroll(className) {
        // Get the leaderboard by class name
        const leaderboard = document.querySelector(className);

        // Get the distance from the top of the document to the top of the leaderboard
        const leaderboardTop = leaderboard.getBoundingClientRect().top;

        // Get the height of the ad container
        let adContainerHeight = document.querySelector(className).offsetHeight;
        const bodyPadding = parseInt(

        );

        const observer = new MutationObserver(function (mutations) {
            setTimeout(function () {
                adContainerHeight =
                    document.querySelector(className).offsetHeight;
                newBodyPadding = bodyPadding + adContainerHeight;
                // console.log('New Height: ' + adContainerHeight + ', Padding: ' + bodyPadding + ', New Padding: ' + newBodyPadding);
            }, 1000);
        });

        const config = { childList: true };

        observer.observe(targetElement, config);

        // Add an event listener for the 'scroll' event
        window.addEventListener('scroll', function () {
            // Get the distance the page has been scrolled
            const scrollY = window.scrollY;

            // If the top of the leaderboard is scrolled to or past, add the class
            if (scrollY >= leaderboardTop) {
                // Prevent function from running more than once
                if (hasExecuted) {
                    return;
                }

                leaderboard.classList.add('sticky');
                this.document.querySelector('body').style.paddingTop =
                    newBodyPadding + 'px';

                // Remove class after 5 seconds and reset body padding
                setTimeout(function () {
                    leaderboard.classList.remove('sticky');
                    this.document.querySelector('body').style.paddingTop =
                        bodyPadding + 'px';
                    hasExecuted = true;
                }, 5000);
            } else {
                // If not, remove the class and reset body padding
                leaderboard.classList.remove('sticky');
                this.document.querySelector('body').style.paddingTop =
                    bodyPadding + 'px';
            }
        });
    }

    // Only run the function if the ad element exists on the page
    if (document.querySelector('.advertisement.fullwidth.adtop')) {
